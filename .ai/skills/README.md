# Codex skills

Skills remain at the Codex-native discovery path `.agents/skills/<name>/SKILL.md`. This index avoids duplicating executable skill files under `.ai`.

- `$fitness-feature`: coordinated feature slice in the existing solution.
- `$fitness-design-check`: UI and design-evidence checks.
- `$fitness-review`: focused code review.
- `$fitness-pr`: branch and PR preparation and review trigger.
- `$fitness-pr-review`: independent PR review and GitHub handoff.
- `$fitness-cleanup-maintenance`: exact `Sæt i gang` cleanup workflow.

Read only the skill needed for the current outcome; supporting skills can be applied at later stages. Agent OS owns task routing; skills own reusable procedures.
