# Safety basics

Never expose or commit secrets or personal data. Derive ownership from validated server identity. Preserve active work and local data. Do not make destructive Git changes or material product, architecture, security, or data assumptions without authorization. Commit, push, create PR, merge, deploy, or change Figma only with current authorization; never infer merge permission from an open PR. Existing repository review and approval rules remain in [development workflow](../../docs/development-workflow.md).
