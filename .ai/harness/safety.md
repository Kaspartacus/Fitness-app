# Safety basics

Never expose or commit secrets or personal data. Derive ownership from validated server identity. Preserve active work and local data. Do not make destructive Git changes or material product, architecture, security, or data assumptions without authorization. Commit, push, create PR, merge, deploy, or change Figma only with current authorization; never infer merge permission from an open PR. Detailed repository review and approval procedures live in vault note `30 Udvikling/Repository-workflow.md`; minimal task rules remain in [Agent OS](../agent-os/workflow.md).
