# Coding standards

Follow nearby C# and Blazor naming, dependency injection, async, logging, and error-handling patterns. Keep boundaries stated in the vault note `20 Arkitektur/Arkitekturoverblik.md` and applicable nested `AGENTS.md`. Use readable code and avoid generic abstractions or new dependencies without a concrete need. When a convention is inconsistent and matters to the outcome, clarify it rather than silently standardizing unrelated code.
