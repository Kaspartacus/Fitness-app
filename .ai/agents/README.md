# Roles and executable agents

These files define responsibilities, not automatically launched agents. Codex-native read-only agents remain discoverable at `.codex/agents/reviewer.toml` and `.codex/agents/security-reviewer.toml`; the exact cleanup agent remains at `.codex/agents/cleanup_maintainer.toml`. Use those native definitions when delegation is authorized and useful. The planner, developer, tester, and finalizer files are role guidance for the active Codex task.
